## Error03
錯誤訊息AttributeError: 'float' object has no attribute 'round'表示該.round()方法無法正確處理準確率。我將改用標準的 Pythonround()函數來解決這個問題，該函數會將準確率四捨五入到小數點後兩位。
```
# df.drop('left', axis=1).corrwith(df['left']).round(2)

```


AttributeError: 'float' object has no attribute 'round'。這個錯誤表示您嘗試在一個浮點數（float）物件上呼叫一個不存在的 .round() 方法。

accuracy_score(y_test, y_pred) 這個函式會回傳一個表示準確度的浮點數（例如：0.75）。
在 Python 中，雖然浮點數可以四捨五入，但它本身並沒有一個可以直接呼叫的 .round() 方法，就像 Pandas DataFrame 或 Series 物件那樣。
正確的做法是使用 Python 的內建 round() 函式來對浮點數進行四捨五入。這個函式接受兩個參數：要四捨五入的數字和要保留的小數點位數。
修正前後的比較：

修正前: print('正確率：', accuracy_score(y_test, y_pred).round(2))

這裡試圖在 accuracy_score() 回傳的浮點數上呼叫 .round(2) 方法，導致了 AttributeError。
修正後： print('正確率：', round(accuracy_score(y_test, y_pred), 2))

現在，accuracy_score(y_test, y_pred) 回傳的浮點數作為 round() 函式的第一個參數，而 2 作為第二個參數指定了保留兩位小數。這樣就能正確地將結果四捨五入並印出，解決了之前的錯誤。
